Terraform Infrastructure Lifecycle
Standard 3-stage plan and apply workflow for declarative provisioning:
Stage 1
terraform init

Downloads the official MongoDB Atlas provider binary and initializes the backend state.

Stage 2
terraform plan

Calculates execution graph diff: creates project, provisions M0 cluster, sets up RBAC user, and adds IP whitelist.

Stage 3
terraform apply

Executes API calls to MongoDB Atlas API, provisions infrastructure, and outputs the SRV cluster URI.
