ACTIVITY 17.2

Compare HNSW and IVF Vector Index Types

Analyze why approximate search exists. Evaluate cluster-based partitioning (IVF) against graph-based greedy navigation (Simplified NSW/HNSW) on synthetic vector datasets. Measure Recall@k and understand why "Vectors Compared per Query" is the true metric of scale.

Core Features:
  • Exact brute-force ground truth (100% Recall baseline)
  • IVF (Inverted File Index) with Lloyd's K-Means clustering
  • Simplified NSW (Hierarchical Navigable Small World relative)
  • Empirical Recall@k calculation vs Ground Truth
  • Deep dive: Vectors Compared per Query vs Python wall-clock time
