Demonstrates the architectural justification for adding Neo4j to the polyglot stack: uncovering coordinated fraud networks sharing hardware device identifiers.

Neo4j: Index-Free Adjacency

Traversing 3 hops of (:User)-[:SHARES_DEVICE]-(:User) follows in-memory memory pointers in O(k) time, completely independent of total database size (whether 10k or 100M transactions).

MongoDB: $graphLookup

MongoDB can search recursive references via $graphLookup, but at 10M+ scale, multiple recursive B-Tree index lookups become memory-intensive and latency-bound.

Cassandra: Fundamental Bottleneck

Cassandra has no graph or join capabilities. Finding accounts sharing devices requires querying each account independently, bringing millions of keys to the client application to compute intersections in code.

Neo4j Cypher Implementation for Production Ring Walk

Target Graph Query 
// Find all secondary and tertiary users linked to target suspect U-0001 via shared devices
MATCH path = (u1:User {id: 'U-0001'})-[:SHARES_DEVICE*1..3]-(u2:User)
WHERE u1 <> u2
WITH u1, u2, COUNT(DISTINCT path) AS shared_signals, COLLECT(DISTINCT [n in nodes(path) WHERE n:Device | n.id]) AS devices
WHERE shared_signals >= 2
RETURN u1.id AS primary_suspect, 
       u2.id AS linked_account, 
       shared_signals, 
       devices
ORDER BY shared_signals DESC 
LIMIT 20;
