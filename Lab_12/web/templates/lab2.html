Encrypted Connection (mTLS)
Must Succeed

Connecting with tls=true, tlsCAFile, and client certificate keyfile.

Expected Outcome: Handshake succeeds over TLS 1.3, encrypted session established.

OpenSSL & PyMongo Configuration Commands
# 1. Generate Root CA Key and Self-Signed Certificate (4096-bit RSA) openssl genrsa -out ca.key 4096 openssl req -new -x509 -days 365 -key ca.key -out ca.crt -subj '/CN=MongoDB-CA/O=NoSQL Security Labs' # 2. Generate Server Key and Certificate Signing Request (CSR) openssl genrsa -out server.key 4096 openssl req -new -key server.key -out server.csr -subj '/CN=localhost/O=NoSQL Security Labs' # 3. Sign Server Certificate with CA (Including SAN for localhost and IP 127.0.0.1) openssl x509 -req -days 365 -in server.csr -CA ca.crt -CAkey ca.key -CAcreateserial \ -out server.crt -extfile <(echo 'subjectAltName=DNS:localhost,IP:127.0.0.1,DNS:mongo') # 4. Concatenate server key and cert for mongod PEM requirement cat server.key server.crt > mongodb.pem chmod 600 mongodb.pem
# Starting MongoDB with mandatory TLS encryption and Certificate Authority validation mongod \ --port 27100 \ --dbpath /data/db \ --tlsMode requireTLS \ --tlsCertificateKeyFile /etc/ssl/mongodb/mongodb.pem \ --tlsCAFile /etc/ssl/mongodb/ca.crt \ --bind_ip_all
from pymongo import MongoClient # Secure TLS-encrypted connection with CA verification & client certificate client = MongoClient( "mongodb://localhost:27100/?tls=true&tlsAllowInvalidHostnames=true", tlsCAFile="tls/ca.crt", tlsCertificateKeyFile="tls/client.pem", serverSelectionTimeoutMS=5000 ) # Test ping command db = client.admin res = db.command("ping") print("[OK] Encrypted TLS Ping Response:", res)
