Proposed Polyglot Architecture

Optimal separation of operational storage and relationship graph

Ch. 16 Synthesis
Why Apache Cassandra is excluded from this architecture: While Cassandra provides unmatched linear write throughput, it requires access patterns to be rigidly hardcoded into partition keys. It cannot perform ad-hoc risk range scans without costly full-cluster table filtering (ALLOW FILTERING) and has no native aggregation engine without standing up an auxiliary Apache Spark cluster.

Architectural Scorecard

At a glance
1. User History Lookup Cassandra > Mongo > Neo4j

Cassandra excels when user_id is the partition key (~2-5ms). MongoDB is virtually identical with index scan (~14ms). Neo4j traverses relationships (~5-15ms).

2. Risk Range Filter Mongo > Neo4j >> Cassandra

MongoDB's B-Tree index scan on risk_score is optimal (~15ms). Cassandra requires secondary indexes or multi-node broadcast filtering (50-200+ ms).

3. Category Analytics Mongo >> Neo4j >> Cassandra

MongoDB native aggregation framework groups in-memory (~10-15ms). Neo4j is inefficient for whole-graph sums. Cassandra requires external Spark.

4. Fraud Ring Traversal Neo4j >>> Mongo >>> Cassandra

Neo4j's index-free adjacency traverses shared-device hops in constant time per edge. MongoDB requires multiple joins or $graphLookup; Cassandra cannot do this natively.

Why Fraud Detection Stresses Database Architectures

A fraud detection platform cannot rely on one single database optimization because it confronts four contradictory access patterns concurrently:

Point Lookups
Fast checkout authorization retrieving a single customer's last 50 transactions to verify velocity.
Attribute Filtering
Fraud investigators filtering transactions with risk score > 0.8 across multiple dimensions and merchants.
Analytical Aggregations
Real-time category spending totals to detect macro shifts and merchant compromise anomalies.
Relationship Traversal
Uncovering synthetic identity theft rings where dozens of accounts share the same physical mobile devices.
