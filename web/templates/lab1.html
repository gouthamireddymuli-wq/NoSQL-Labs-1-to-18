How Tenant Scoping Works

In a shared collection architecture, MongoDB does not enforce isolation at the storage level. The software layer must inject tenant_id into every query.

# Python / PyMongo update query: col.update_one( {"_id": task_id, "tenant_id": tenant_id}, {"$set": updates} )
Result: If an unauthorized tenant supplies a valid _id belonging to another customer, the compound query yields 0 matching documents, eliminating cross-tenant leakage.
