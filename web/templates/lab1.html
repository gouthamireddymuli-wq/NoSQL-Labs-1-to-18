Build a Simple RAG Pipeline & Prompt Engineering

Core RAG Concepts & Prediction Guide
1. Vector Embeddings: Transforms text into a 384-dimensional geometric coordinate where similar meanings are placed close together.
2. Cosine Similarity: $\cos(\theta) = \mathbf{a} \cdot \mathbf{b}$. Since mock vectors are pre-normalized to unit length ($\|\mathbf{a}\|=1$), similarity equals the dot product.
3. Mock vs. Real: Mock embeddings hash strings deterministically (zero API cost, fully offline), but lack real semantic meaning. Real models (VoyageAI, OpenAI) encode true language semantics.
4. The RAG Flow: Chunk text $\rightarrow$ Embed $\rightarrow$ Store in MongoDB $\rightarrow$ Embed query $\rightarrow$ Cosine similarity $\rightarrow$ Prompt construction $\rightarrow$ LLM generation.
